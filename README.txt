palentweb website - full version (all updates included)

What is inside:
  index.html   -> the complete website. Everything is inside this one file:
                  pages (Home, Services, Pricing, Work, About, Contact, Privacy & terms),
                  top menu + phone sidebar, full-size intro film with music,
                  12 live demo stores, giftbox377 + PriceLock projects,
                  Instagram / Facebook / TikTok links, WhatsApp button, footer.
  extras/      -> NOT needed for the website. Just for you:
                  palentweb_film_music.mp3  (the film music)
                  palentweb_film_with_music.mp4 (preview of the intro film)

How to upload to GitHub:
  1. Open your repository and delete or replace the old index.html.
  2. Add file -> Upload files -> drag index.html (the name must stay exactly index.html).
  3. Commit changes, wait 1-2 minutes, then refresh with Ctrl+Shift+R.

طريقة الرفع على GitHub:
  1. افتح المستودع واحذف أو استبدل ملف index.html القديم.
  2. Add file ثم Upload files واسحب ملف index.html (الاسم لازم يضل index.html بالضبط).
  3. اضغط Commit changes واستنى دقيقة أو دقيقتين، وبعدين حدّث الصفحة بـ Ctrl+Shift+R.
ملاحظة: مجلد extras مش ضروري للموقع، هو بس للموسيقى ومعاينة الفيديو.
